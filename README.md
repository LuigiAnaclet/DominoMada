# Jeu de Dominos Multijoueur (Unity)

Projet personnel en cours : un jeu de dominos en ligne avec IA intégrée, développé sous Unity.

## 🎮 Fonctionnalités déjà implémentées
- Distribution aléatoire des dominos
- Affichage du plateau
- Tour par tour en solo et multijoueur (via Photon)
- Détection des coups jouables
- IA stratégique (DQN)

## 🧠 Objectifs à venir
- Refonte graphique (système de "skins")
- Classement en ligne

## 🛠 Stack
- Unity + C#
- Photon Unity Networking
- Unity ML-Agents
